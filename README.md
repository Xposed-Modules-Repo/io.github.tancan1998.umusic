# U 音

当前版本 **1.2**，内部版本码 13，沿用正式签名。新增「显示启动 toast」和「屏蔽我的页下拉金币入口」两个开关。

QQ 音乐净化模块，使用现代 libxposed API 102。入口为「我的」→ 右上角更多 →「U 音设置」。

源码与构建说明见 [U 音源码仓库](https://github.com/TanCan1998/umusic)。

## 已实测宿主版本

- **QQ 音乐 21.0.0.8 / 7708**（`com.tencent.qqmusic`）于 2026-11-19 本机验证原生设置、启动提示开启与关闭后的冷启动，以及「我的」页下拉金币入口的拦截和恢复。
- **QQ 音乐 20.9.8.8 / 7608** 已验证既有净化功能，以及会员成长值、金币中心和抽奖页签到。

## 自动签到与领奖

覆盖普通日签、会员成长值、金币中心和抽奖页签到，分别去重并显示结果。签到后查询服务器状态，领取签到关联奖励后再次查询。失败与未知结果不记成功。

其他同协议活动可在宿主打开页面时识别。看广告、分享、邀请与播放时长任务不属于直接签到。自动签到在宿主运行且账号已登录时触发。

模块还提供广告净化、会员引导整理、本地会员显示与音效、金币入口整理及元宝入口开关。本地会员不提供云端付费内容权益。
