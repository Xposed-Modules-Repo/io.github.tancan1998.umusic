# U 音

QQ 音乐净化模块，使用现代 libxposed API 102。入口：我的 → 右上角更多 → 原设置下一行「U 音设置」。

源码与构建说明：https://github.com/TanCan1998/umusic

## 0.10：自动签到与领奖修复

覆盖普通日签、会员成长值、金币中心和抽奖页签到，分别去重并显示结果。签到后查询服务器状态，领取签到关联奖励后再次查询，失败与未知结果不记成功。修复会员 20028“今天还未领取”分支，以及金币数字 IsSignIn 的判定。

2026-11-07 已在 QQ 音乐 20.9.8.8 / 7608 实机确认会员成长值、金币中心、抽奖页签到结果；当前日签金币页面显示“明日签到领160金币”。其他同协议活动可在宿主打开页面时识别，未保证覆盖所有限时活动。广告、分享、邀请与播放时长任务不属于直接签到。

模块仅在已登录宿主运行时触发，无独立后台定时服务。真实切号本次未重做，账号隔离通过 JVM 回归。

提供广告净化、会员引导整理、本地会员显示与音效、金币入口整理及元宝入口开关。本地会员不提供云端付费内容权益。新版本沿用正式签名，可覆盖更新 0.9；不要同时启用旧包名模块。
